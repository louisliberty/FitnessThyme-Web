FITNESSTHYME — FULL REBUILD PROMPT FOR REPLIT

You are rebuilding FitnessThyme, a two-sided fitness marketplace that matches clients with trainers, yoga instructors, Pilates teachers, nutritionists, gyms, and specialty coaches. The current site is a single static HTML file with inline CSS and vanilla JavaScript. You are upgrading it into a fully featured, industry-leading connection platform. Keep the existing design system exactly as-is: sage-green and tan palette, Playfair Display for headlines, DM Sans for body text, the 🌿 logo, and the warm earthy brand voice. Do not change the visual identity. Only add, upgrade, and wire up new functionality on top of it.

SECTION 1 — MATCHING QUIZ (build this first, it is the most important feature)
When a new client lands on the site or clicks "Find My Trainer" or "Get Started," before showing them the browse page, show them a full-screen onboarding quiz. This quiz should feel smooth and progressive — one question per screen with an animated transition between steps. Do not show all questions at once.
The quiz steps are:
Step 1 — "What's your primary goal?" (single select with icon cards): Lose weight / Build muscle / Improve flexibility / Reduce stress / Prenatal fitness / Postpartum recovery / Injury rehabilitation / Train for competition / Senior fitness / General health and wellness
Step 2 — "What's your current fitness level?" (single select): Complete beginner / Some experience / Intermediate / Advanced / Athlete
Step 3 — "How do you prefer to train?" (multi-select): One-on-one sessions / Small group / I like structure and a plan / I prefer flexibility / I want accountability check-ins / I learn best by watching / I want someone who pushes me hard / I prefer a gentler, supportive style
Step 4 — "What format works best for you?" (single select with icons): In-person only / Virtual only / Either works for me
Step 5 — "What's your weekly availability?" (multi-select days + time of day): Days: Mon / Tue / Wed / Thu / Fri / Sat / Sun. Time: Early morning (6–9am) / Morning (9am–12pm) / Afternoon (12–5pm) / Evening (5–9pm)
Step 6 — "What's your budget per session?" (single select): Under $50 / $50–$75 / $75–$100 / $100–$150 / $150+
Step 7 — "Anything else we should know?" (optional free text field with placeholder: "injuries, preferences, things that haven't worked before...")
After Step 7 show a "Finding your matches..." loading screen for 1.5 seconds with an animated progress bar, then redirect to the browse page with results pre-filtered and each trainer card showing a Match Score percentage badge (e.g. "94% Match") calculated from how well the trainer's profile aligns with the client's quiz answers. Store the quiz answers in localStorage so the experience is remembered across the session.
Add a "Retake Quiz" button on the browse page that resets localStorage and restarts the quiz.

On every trainer profile page, update the review system as follows:
Each review card must include five structured fields displayed in this order:

Reviewer name and star rating (existing)
Goal tag (existing — e.g. "Goal: Postpartum recovery")
Review text (existing)
Outcome statement — a bold one-line result in sage green, formatted like: "Result: Lost 22 lbs over 4 months" or "Result: Completed first 5K at age 61" or "Result: Returned to lifting 6 weeks postpartum." Display this prominently below the review text.

Add at least 4 sample reviews per profile with realistic, specific outcome statements. Add a review summary bar at the top of the reviews section showing: average star rating as a large number, a 5-row star breakdown bar chart (5 stars / 4 stars / etc. with percentage fill bars in sage green), and total review count.

SECTION 4 — IN-PLATFORM MESSAGING
Add a Messages section accessible from the nav bar (add a "Messages" link between "Find a Trainer" and "List Your Practice"). This should be a full page (id="page-messages") with a two-panel layout: left panel is a conversation list, right panel is the active chat thread.
The conversation list shows: trainer avatar (initials circle), trainer name, last message preview, and timestamp. Pre-populate with 2 sample conversations — one with Maya Rodriguez and one with James Kwon.
The chat panel shows: a header with the trainer's name and a "View Profile" button, a scrollable message thread with alternating left (trainer) and right (client) bubbles, and a message input bar at the bottom with a send button.
Messages should be functional within the session — typing and pressing Send or hitting Enter should add the message to the thread as a right-aligned bubble. Store messages in localStorage so they persist across page navigations within the same session.
Style the chat bubbles: client messages in sage green with white text, trainer messages in light gray with dark text. Use DM Sans throughout.

SECTION 5 — CLIENT DASHBOARD
Add a Dashboard page (id="page-dashboard") accessible from the nav when "signed in." Add a "Dashboard" link to the nav bar that appears after the user completes the quiz or signs up. The dashboard has four sections laid out in a clean grid:
Section A — Upcoming Sessions: Show 2 sample upcoming sessions as cards. Each card shows: trainer avatar, trainer name, session type (Virtual or In-Person), date and time, a "Join Session" button (for virtual) or "Get Directions" button (for in-person), and a "Reschedule" link.
Section B — Saved Trainers: Show 3 trainer cards in a horizontal scroll row (the same card format as browse, but compact). Add a heart/bookmark icon to every trainer card on the browse page and profile page — clicking it adds them to this saved section.
Section C — Progress Notes: A simple personal journal. Show a text area with the placeholder "How did today's session go? Note your energy, what you worked on, how you felt..." and a "Save Note" button. Below show saved notes as timestamped cards in reverse chronological order. Store in localStorage.
Section D — My Match Profile: Show the client's quiz answers as a summary card with an "Edit / Retake Quiz" button that restarts the quiz flow.
