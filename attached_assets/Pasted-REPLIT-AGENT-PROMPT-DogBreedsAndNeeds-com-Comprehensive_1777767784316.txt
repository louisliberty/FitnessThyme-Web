You are working on an existing full-stack web application called DogBreedsAndNeeds.com — a comprehensive dog breed directory and educational resource. 1. BREED CONTENT REWRITE SYSTEM
The current breed content reads as templated and generic. We need a system to support genuine, deep, breed-specific content.

Add a contentQuality enum field to the breeds table: templated | draft | reviewed | verified
Add a lastUpdated timestamp field to every breed record
Add a reviewedBy text field (e.g., "Dr. Jane Smith, DVM")
Add a funFacts array field (3–5 bullet-point facts per breed)
Add a commonMisconceptions text field per breed
Add a idealOwnerProfile text field describing the ideal human match in plain language
Add a notGoodFor text field — honest list of lifestyle mismatches (e.g., "Not ideal for apartment dwellers, first-time owners, or those with limited outdoor access")

Content fields to expand (ensure these exist and are non-empty and non-generic for every breed):

personality — minimum 150 words, breed-specific, written in warm authoritative voice
history — minimum 100 words, actual breed origin story
livingWith — practical day-in-the-life description for owners
trainingTips — breed-specific advice, not generic dog training tips
healthCare — specific known health issues for this breed, not placeholder text
dietaryNeeds — tailored nutritional guidance
groomingGuide — specific coat type, tools needed, frequency

Admin panel additions:

Add a content quality indicator badge next to each breed in the admin list
Add a "Content Completeness Score" that checks field length and flags breeds with templated/short content
Add a markdown editor for all long-form text fields so admins can write rich content
